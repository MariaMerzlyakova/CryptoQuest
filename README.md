# CryptoQuest

Реализовано:  
Система регистрации с валидацией пароля, вход в профиль, сохранение прогресса в SQLite  
5 шифров (Кардано, Виженера, Плейфера, Вернама, Полибия) с теорией и задачами  
Проверка ответов с подсветкой полей, прогресс-бары, общий счет баллов  
Подсказки за баллы, рейтинг игроков
